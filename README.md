# 🧸 Dunia Belajar Davin

Aplikasi permainan edukasi interaktif berbasis web yang dirancang khusus untuk balita (usia 2 tahun) dengan tampilan warna-warni, tombol besar ramah sentuhan, animasi ceria, efek suara sintetis, serta narasi suara Bahasa Indonesia.

## ✨ Fitur Utama
- **🔤 Belajar Alfabet (A–Z):** Mengenal huruf lengkap beserta contoh kata dan emoji visual.
- **🔢 Belajar Berhitung (1–10):** Mengenal angka dan menghitung jumlah benda secara visual.
- **🦁 Mengenal Binatang:** Mengenal berbagai hewan liar beserta efek suara khasnya.
- **🐄 Hewan Ternak:** Mengenal hewan-hewan di peternakan dengan suara interaktif.
- **🎯 Mode Tebak Gambar & Hadiah Bintang:** Kuis interaktif sederhana dengan pujian suara dan perayaan konfeti.
- **🔊 Narasi Suara & Musik Ceria:** Menggunakan Web Speech API (Bahasa Indonesia) dan Tone.js tanpa memerlukan aset audio eksternal.

## 🚀 Cara Menjalankan
Cukup buka file `index.html` di browser modern (Chrome, Safari, Edge, atau Firefox), atau akses melalui **GitHub Pages** setelah repositori di-hosting.

## 🛠️ Teknologi yang Digunakan
- HTML5 & CSS3 (Custom Animations)
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- [Tone.js](https://tonejs.github.io/) (Sintesis musik latar & efek suara)
- [Canvas Confetti](https://www.kirilv.com/canvas-confetti/) (Efek perayaan bintang)
- Web Speech API (`id-ID` Text-to-Speech)
